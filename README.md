# أُلفة العائلة · Olfa Family

**نقرّب القلوب... ونبني تفاهماً يدوم**

تطبيق ويب عربي يقوّي الروابط الأسرية، يجمع أفراد العائلة في مساحة واحدة دافئة،
ويساعدهم يتفاهمون أكثر بالاستشارات الذكية والأنشطة المشتركة.

### 🔗 [جرّب التطبيق الآن](https://aljouriabushal.github.io/Olfa-Family/)

</div>

## 💡 المشكلة

مع انشغال الحياة والجوالات، صار أفراد العائلة الواحدة يعيشون في نفس البيت لكن بعيدين عن بعض.
كثير من الخلافات الصغيرة تكبر لأننا ما نعرف كيف نبدأ الحوار، والأبناء أحياناً ما يلقون مكان آمن يفضفضون فيه.

## 🌱 الحل

**أُلفة** مساحة رقمية للعائلة تحوّل التواصل اليومي لعادة لطيفة:
تسمع لكل فرد، تقترح عليه خطوات عملية، وتجمع العائلة على أنشطة وتحديات تقرّبهم من بعض.

## ✨ المميزات

### 👨‍👩‍👧 مساحة العائلة
- إنشاء مساحة للعائلة والحصول على **كود دعوة من 6 أرقام**
- عرض **أفراد العائلة** المنضمين بنفس الكود، ومين **متصل الآن** ومين آخر ظهوره
- **نقاط العائلة** المشتركة: كل إنجاز لأي فرد يرفع رصيد العائلة كلها
- **تقرير أسبوعي** تلقائي بالذكاء الاصطناعي عن تفاعل العائلة

### 💬 استشارات «أُلفة AI»
- محادثة دافئة مع مساعد ذكي يقدّم نصائح أسرية عملية بلغة بسيطة
- **الكتابة بالصوت** 🎙️ للي يفضّل يتكلم بدل ما يكتب
- **أسئلة شائعة** جاهزة لأكثر المواقف اللي تمر فيها العائلات

### 😊 مزاج العائلة ورسائل الامتنان
- كل فرد يختار **مزاجه اليومي** بضغطة، ويظهر لعائلته جنب صورته
- إرسال **رسائل امتنان** لفرد معيّن تظهر في مساحة العائلة (+5 نقاط)

### 🧩 أنشطة وتحديات أسبوعية
- **ألعاب ومسابقات**: السيرة النبوية، مدن المملكة، أسئلة إسلامية، أكمل المثل، معلومات عامة
- **حكمة اليوم**: يكتب الفرد حكمة، ويقيّمها الذكاء الاصطناعي ويمنحه نقاط
- **تحديات واقعية** للعائلة: صلاة الفجر، كلمة طيبة يومياً، جلسة بدون جوال...
- تتجدد **تلقائياً كل أسبوع**، ونصيحة واقتراح جديد **كل يوم**

### 🆘 الدعم والنصائح
- **أرقام الدعم الرسمية** في السعودية (العنف الأسري 1919، مساندة الطفل 116111، الاستشارات النفسية 920033360...)
- **نصائح حسب العمر**: مع الطفل، مع المراهق، للأبناء مع الوالدين، وبين الزوجين

### ♿ سهولة الاستخدام
- **جولة تعريفية** لأول مرة
- **الوضع الليلي** 🌙 و **تكبير الخط** لكبار السن
- **عربي / English** بضغطة
- **يُثبَّت كتطبيق** على الجوال 📲 (PWA) ويفتح بدون متصفح

## 🛠️ التقنيات

| الجزء | التقنية |
|---|---|
| الواجهة | HTML · CSS · JavaScript (بدون مكتبات) |
| الاستضافة | GitHub Pages |
| السيرفر | Cloudflare Workers |
| قاعدة البيانات | Cloudflare Workers KV |
| الذكاء الاصطناعي | Groq API |
| التطبيق على الجوال | Progressive Web App (Manifest + Service Worker) |

## 🔒 الخصوصية والأمان
- **مفتاح الذكاء الاصطناعي محفوظ في السيرفر** وما يظهر أبداً في كود الموقع
- **كلمات السر مشفّرة** (PBKDF2 مع salt) وما تنحفظ كنص
- السيرفر **يقبل الطلبات من موقع أُلفة فقط**
- المحادثات الخاصة **ما تدخل في تقرير العائلة**، والتقرير يعتمد على الأرقام فقط
- عند ذكر أي خطر أو أذى، يوجّه المساعد الشخص للتواصل مع شخص بالغ يثق فيه وأرقام الطوارئ
